# **App Name**: VisionaryAI

## Core Features:

- Text-to-Image Generation: Generates images based on user-provided text prompts using AI.
- Image Editing: Basic image editing functionality (cropping, resizing, rotating) for generated images.
- Image Variation: Generates variations of an existing image using AI, based on subtle changes in the prompt.
- Image Gallery: Allows users to save and view their generated images.
- Prompt Suggestions: Suggests prompts to inspire image generation. This can be done through a tool to use keywords related to the last search.

## Style Guidelines:

- Primary color: Deep violet (#7955D4) to evoke creativity and imagination.
- Background color: Light gray (#F0F2F5) for a clean and unobtrusive canvas.
- Accent color: Soft lavender (#C5B3E6) to highlight interactive elements.
- Body and headline font: 'Inter', a sans-serif for modern UI readability and neutrality.
- Simple, line-based icons with a subtle animation on hover.
- Clean, modern layout with a focus on visual clarity.
- Subtle animations and transitions to enhance user experience.
